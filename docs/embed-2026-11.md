## 높이 메시지 이름 — 두 이름 같이 보내는 기간

사양은 **`{ type: "blog-rank:height", height }`** 다. 처음 구현은 `blogrank-embed-height` 로
나갔고, CPR OS 쪽에 이미 옛 이름을 듣는 코드가 있을 수 있어 **두 이름을 같이 보낸다.**

| | |
|---|---|
| 사양 이름(앞으로 쓸 것) | `blog-rank:height` |
| 옛 이름(같이 보내는 중) | `blogrank-embed-height` |
| 같이 보내기 시작 | **2026-11-21** (커밋으로 배포) |
| **옛 이름 제거 예정일** | **2026-12-05** |
| 제거할 곳 | `api/embed.js` `tellHeight()` 안의 `blogrank-embed-height` 줄 1개 |

받는 쪽 예시:
```js
window.addEventListener('message', (e) => {
  if (e.origin !== 'https://blog-rank-phi.vercel.app') return;
  if (!e.data || e.data.type !== 'blog-rank:height') return;
  iframe.style.height = e.data.height + 'px';
});
```

**높이 0은 보내지 않는다.** 부모 페이지가 그려지는 중에 0이 측정된 적이 있고(2026-11-16 확인),
부모가 그 값을 쓰면 틀이 접혀 아무것도 안 보인다. `tellHeight()` 가 `if (!h) return;` 으로 막는다.
이 동작은 이름을 바꿔도 그대로 둔다.
