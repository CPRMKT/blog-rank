## 3. 수집 점검(cron_watchdog) 개정·등록

**읽는 것:** 네이버는 조회하지 않는다. 읽는 것은 서버 로그 3가지뿐이다.
- 수집 로그
- pm2 로그
- `.git/logs/HEAD` (오늘 배포 횟수)

**알리는 경우(이것만):**
- **회차 미시작:** 12:30 점검에서 블로그·플레이스 아침 회차가 시작 기록이 없을 때. 22:40 점검에서 저녁 회차(2회째)가 시작 기록이 없을 때.

  - 백오프 대기가 35분이라 그보다 길게 잡았다.
  - 6시간으로 자동 상향된 저녁 회차처럼 진행 중이면 알리지 않는다.
- **재시작 초과:** 오늘 재시작이 "정기 1회 + 오늘 배포 횟수"를 넘을 때. 명령 없이 죽었다 뜬 재시작이 1회라도 있을 때.
