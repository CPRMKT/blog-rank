# 화면에 유실 구간 표시 — 시안 (2026-11-21, 승인 대기 · 미적용)

시안 캡처: [loss-notice-mockup.jpg](restore-2026-11/loss-notice-mockup.jpg)
(실제 `index.html` 의 CSS 와 실제 데이터(서울쭈꾸미쌈겹 — 석촌역 맛집 / 석촌 쭈꾸미)로 그린 목업이다.
위쪽이 지금 화면, 아래쪽이 시안.)

## 왜 필요한가
지금은 10/26~11/10 칸이 **"수집 안 됨"** 으로 나온다. 화면 설명에 "그날 수집 기록 자체가 없음"이라고 적혀 있어
**"그 16일은 수집을 안 했다"** 로 읽힌다. 실제로는 수집했고 기록이 유실된 것이다.

## 바꾸는 것 3가지

| # | 어디 | 지금 | 시안 |
|---|---|---|---|
| 1 | 플레이스 순위 추적 카드의 날짜 칸 | `수집 안 됨` (회색 점선) | **`유실`** (호박색 글자 + 옅은 호박색 칸). 말풍선: "이 기간(10/26~11/10) 기록이 유실되었습니다 — 순위가 없었다는 뜻이 아닙니다" |
| 2 | 카드 목록 위 | 없음 | 한 줄 안내 — "ⓘ 2026-10-26 ~ 11-10 플레이스 순위 기록이 유실되었습니다. 해당 날짜는 **유실**로 표시됩니다 — 순위가 없었다는 뜻이 아닙니다. 11/11 이후 수집은 정상입니다." **화면에 보이는 날짜 중 유실 구간이 있을 때만** 뜬다 |
| 3 | 날짜 비교 탭 | 기준일이 유실 구간이면 **아무 말 없이** 더 오래된 날짜(10/25)로 넘어간다 — "20일전"이라 적혀 있는데 실제로는 27일 전과 비교 | 해당 탭에 **⚠**, 표 위에 "⚠ 20일 전(11/01)은 기록이 유실된 기간(10/26~11/10)입니다. 가장 가까운 이전 수집일 **10/25** 기준으로 비교합니다." |

- 유실 구간 안이라도 **행이 있는 칸은 그대로 순위를 보여 준다**(되살린 16쌍 — 석촌 쭈꾸미 10/30~11/09 등).
  "유실" 은 **그날 그 키워드의 수집 기록이 없을 때만** 붙는다.
- 날짜 비교 탭의 기존 경고(`PR_BAD_FROM='2026-10-29'`~`'2026-11-09'`, "수집 오류 기간")는 **이 상수로 대체**한다.
  그 구간의 남은 행은 전부 정상 판정된 16쌍뿐이라 옛 경고는 더 이상 맞지 않는다.
- 기본 비교 기준일에서의 제외: 유실 날짜는 **데이터가 없어 기준일 후보에 애초에 안 들어간다.**
  바뀌는 것은 "조용히 넘어감" → "넘어갔다고 알림" 이다.

## 상수는 한 곳
```js
// index.html — 플레이스 순위 기록 유실 구간(2026-11-14 사고). 2026-12-11 이후 이 상수와 쓰는 곳 3군데를 지운다.
// (경위: docs/place-loss-final-2026-11.md / 제거 방법: docs/place-loss-notice-proposal-2026-11.md)
const PLACE_LOSS = { from: '2026-10-26', to: '2026-11-10' };
const placeLost = (d) => !!d && d >= PLACE_LOSS.from && d <= PLACE_LOSS.to;
```

## 2026-12-11 이후 제거 방법
순위 카드는 최근 30일, 날짜 비교는 최근 31일을 본다. **12/11 이면 11/10 이 양쪽 창에서 다 빠진다.**
1. `index.html` 에서 `PLACE_LOSS` 를 검색 → 상수 2줄, 쓰는 곳 3군데(칸 렌더 1, 안내 줄 1, 비교 탭 1)를 지운다.
2. CSS `.pt-lost`, `.pt-day.lost`, `.pt-lossnote` 3줄을 지운다.
3. 화면 설명 문구의 "유실" 항목을 지운다.
4. `check_dom_refs.mjs` 를 돌려 남은 참조가 없는지 확인.
지우지 않아도 **동작에는 문제가 없다**(해당 날짜가 화면에 안 나오면 아무 일도 안 한다). 죽은 코드가 남을 뿐이다.

## 임베드 화면
임베드는 **최근 12일**만 보여 준다(`api/embed.js` `lastDays(12)`).
- 오늘(11/21) 창: 11/10~11/21 → 유실 구간은 **11/10 하루**만 걸린다.
- **내일(11/22)부터는 창이 11/11~11/22 라 유실 구간이 하나도 안 보인다.**

→ **임베드에는 넣지 않는 것을 권한다.** 넣어도 오늘 하루만 의미가 있고 내일부터 죽은 코드다.
